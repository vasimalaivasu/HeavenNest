HavenNest Lodge HTML Template

Comprehensive buyer customization and implementation guide for HavenNest — modern Budget Hotel & Lodge HTML Template.

Introduction

Thank you for purchasing HavenNest Lodge! This template is a production-ready, clean, lightweight HTML5 template designed specifically for budget hotels, guest lodges, homestays, highway transit stays, and small multi-branch hospitality businesses.

Zero Build Tool Requirements: You don’t need Node.js, Webpack, npm, or any compilers to run or edit this website. Simply open any HTML file directly in your browser or upload the files to any web host (Apache, Nginx, cPanel, Vercel, Netlify, or GitHub Pages).

Key Features

  • Original Budget Hotel Aesthetic: Warm off-white surfaces, deep navy brand base, and warm terracotta accent for CTAs.
  • Interactive Booking Enquiry Form: Real-time price estimator, night count calculator, date validation, and reference ID generation.
  • Direct WhatsApp Deep-Linking: One-click button that pre-populates the booking enquiry directly to the lodge’s WhatsApp number.
  • Light & Dark Mode: Built-in toggle with automatic LocalStorage preference persistence.
  • Full RTL (Right-to-Left) Support: Native logical CSS properties for Arabic and Hebrew layouts.
  • Accessible Modal & Lightbox: Interactive photo gallery lightbox with arrow navigation and detailed room modals.
  • Zero Dead Buttons: Every button, link, stepper, and counter is interactive.
  • Structured SEO Data: Pre-configured Schema.org LodgingBusiness and ContactPage JSON-LD snippets.

Brand & Contact Info Customization

To update the lodge name, phone numbers, and addresses, update the following files:

  • Hotel Name & Tagline: Search for HavenNest in all HTML files and replace with your business name.
  • Social & Login Links: In the footer of each HTML file, update the Facebook (https://www.facebook.com/login/), Instagram (https://www.instagram.com/accounts/login/), and Twitter (https://twitter.com/i/flow/login) links to your preferred profile or login destinations.
  • Phone Number: Update the tel:+18004567890 links in the footer, contact page, and banners.
  • WhatsApp Number: In assets/js/modules/enquiry-form.js, change hotelNumber = "919876543210" to your international phone number (without + or hyphens).

Colors & Theming Customization

All colors are centralized in assets/css/style.css within the :root block: 

:root {
  /* Brand Navy */
  --brand-navy: #0B253A;
  --brand-navy-light: #16364F;

  /* Primary Accent (Used for All Main Action Buttons) */
  --brand-accent: #D96B27;
  --brand-accent-hover: #BF5A1B;

  /* Surfaces (Light Theme) */
  --bg-page: #FAF7F2;      /* Warm off-white / cream */
  --bg-surface: #FFFFFF;   /* Clean white cards */
}

/* Dark Theme Colors */
[data-theme="dark"] {
  --bg-page: #081119;      /* Deep midnight navy */
  --bg-surface: #101E2B;   /* Elevated dark card */
}

Image Replacement

All photography is organized cleanly in a single configuration file: assets/js/data/images.js. You can swap any Unsplash URL with your own local file path (e.g. assets/images/rooms/deluxe.jpg) in this file: 

const HOTEL_IMAGES = {
  property: {
    hero: "assets/images/property/hero.jpg",
    reception: "assets/images/property/reception.jpg",
    dining: "assets/images/property/dining.jpg"
  },
  rooms: {
    standardDouble: "assets/images/rooms/standard.jpg",
    deluxeDouble: "assets/images/rooms/deluxe.jpg"
  }
};

Connecting The Booking Enquiry Form

By default, the template runs completely client-side. When a guest submits an enquiry:

  1. A unique enquiry reference number (e.g., ENQ-2026-8341) is generated.
  2. The enquiry is logged into LocalStorage for reviewer / demo proof.
  3. A confirmation summary screen is displayed.
  4. A direct Send via WhatsApp button is populated with all details pre-formatted.

Option A: Formspree (Free Email Forwarding)

If you want enquiries sent directly to your inbox without writing backend code: 

<!-- In contact.html: replace <form id="booking-enquiry-form"> with: -->
<form action="https://formspree.io/f/YOUR_FORMSPREE_ID" method="POST">
  <!-- All inputs with name attributes will be forwarded to your email! -->
</form>

Option B: EmailJS Integration

To trigger emails directly from client-side JavaScript via your Gmail or Outlook account: 

// 1. Include EmailJS SDK in contact.html:
<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/email.min.js"></script>

// 2. In enquiry-form.js inside handleSubmit:
emailjs.send("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", enquiryRecord, "YOUR_PUBLIC_KEY")
  .then(() => {
    Toast.success("Confirmation email dispatched!");
  });

Option C: Direct WhatsApp Delivery (Pre-Installed)

Small lodges and guest houses frequently prefer WhatsApp over emails because it allows direct 2-way chat with the guest. This feature is already fully integrated into HavenNest and requires zero third-party subscriptions.
